# golden-self-made-man

Thư viện tự học để:

1. Phát triển bản thân
2. Lên kế hoạch khởi nghiệp
3. Học về đầu tư

## Cấu trúc

- `/library/self-development`: tài liệu phát triển bản thân
- `/library/startup-planning`: tài liệu lập kế hoạch khởi nghiệp
- `/library/investing`: tài liệu học đầu tư

## Cách sử dụng

1. Chọn 1 mục tiêu chính trong tuần.
2. Đọc tài liệu trong thư mục tương ứng.
3. Ghi lại bài học và hành động trong file ghi chú cá nhân.
4. Cuối tuần đánh giá tiến độ và cập nhật kế hoạch.
