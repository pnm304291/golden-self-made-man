# Self Development Library

## Mục tiêu

- Xây nền tảng kỷ luật
- Cải thiện tư duy và năng suất
- Tăng năng lực giao tiếp và lãnh đạo bản thân

## Lộ trình gợi ý (4 tuần)

1. Tuần 1: Kỷ luật cá nhân (thói quen, quản lý thời gian)
2. Tuần 2: Tư duy tăng trưởng và phản biện
3. Tuần 3: Giao tiếp và thuyết trình
4. Tuần 4: Tổng kết, giữ thói quen, tối ưu lịch học
