# Startup Planning Library

## Mục tiêu

- Xác định vấn đề và khách hàng mục tiêu
- Thiết kế mô hình kinh doanh khả thi
- Lập kế hoạch triển khai MVP

## Khung kế hoạch gợi ý

1. Problem: Vấn đề nào đáng giải quyết?
2. Customer: Khách hàng đầu tiên là ai?
3. Solution: Giải pháp cốt lõi là gì?
4. Revenue: Kiếm tiền bằng cách nào?
5. MVP: Phiên bản tối thiểu cần làm trong 4–8 tuần
6. Metrics: Chỉ số đo tiến độ quan trọng
