# Investing Library

## Mục tiêu

- Nắm nguyên tắc đầu tư cơ bản
- Hiểu quản trị rủi ro
- Xây kế hoạch tích sản dài hạn

## Lộ trình gợi ý

1. Kiến thức nền tảng: lãi kép, phân bổ tài sản, biên an toàn
2. Quản trị rủi ro: đa dạng hóa, tỷ lệ tiền mặt, kỷ luật cắt lỗ
3. Thực hành: lập kế hoạch đầu tư theo tháng/quý
4. Đánh giá: đo hiệu suất và điều chỉnh chiến lược
